First milestone

  1. Change a Python signature without saving.
  2. Open Callers: see evidenced mismatches against the current buffers.
  3. Fix callers without saving: outdated findings disappear after re-analysis.
  4. Save: run eligible saved-code tests under project policy.
  5. Restart either side: synchronize buffers and recover work without reviving old findings as fresh.

Proposed scope: one active editor view per workspace; Errors and Callers first; models optional. Testing unsaved code in an isolated copy is a separate scope decision.
